# matrimoniosemplice-video

Video promozionali e di prodotto per MatrimonioSemplice, in italiano. Le regole di lavoro sono in `CLAUDE.md`.

## Struttura

- `brand/` — design system, token e documenti di riferimento del brand
- `briefs/` — brief e storyboard dei singoli video
- `engine/` — codice di rendering
- `out/` — export (non versionato)
- `assets/audio/`, `assets/fonts/`, `assets/logo/` — musica, font e loghi con licenza chiara
- `_refs/` — riferimenti esterni (non versionato)
- `.claude/skills/` — skill del progetto
